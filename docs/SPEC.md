# Fedo — design spec status

This file was the pixel-level French specification for the macOS app's
notch UI (dimensions, views, states, emotes), generated from a prototype
that lived in that app's own repo. Fedo forked the island UI/UX but has no
macOS build and no notch, so that spec no longer describes anything this
repo ships.

See `FEDO.md` for Fedo's own spec, and `docs/FEDO-NOTES.md` for decisions
and limitations recorded as Fedo's phases land.
