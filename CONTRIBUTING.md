# Contributing to Fedo

Fedo is a personal tool built for one machine (FEDO.md §0), not an
open-source project looking for contributors. If you've forked it for
yourself: the build plan is [`FEDO.md`](FEDO.md), decisions and known
limitations are in [`docs/FEDO-NOTES.md`](docs/FEDO-NOTES.md), and the app
code's own conventions are in [`CLAUDE.md`](CLAUDE.md).

The original project this was forked from, [coucou](https://github.com/Louis-CFM/coucou),
does take contributions — see its own `CONTRIBUTING.md` if that's what
you're looking for.
